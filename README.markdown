# @asl-19/string-scripts

CLI utilities for converting strings JSON files to/from CSV (for translation) and syncing strings JSON files.

This package provides three CLI tools:

- **convertStringsJsonToCsv**: Convert a strings JSON file to a CSV for translators
- **convertStringsCsvToJson**: Merge translations from a CSV back into a strings JSON file
- **syncAndSortStrings**: Add missing strings from a source (usually English) strings JSON file to other strings JSON files, and sort them by key

## Install

```sh
npm install --save-dev @asl-19/string-scripts
```

[Prettier](https://prettier.io/) 3 is a peer dependency. JSON files are formatted using the consuming project’s Prettier version and config.

## Usage

All arguments are required.

### convertStringsJsonToCsv

```sh
npx convertStringsJsonToCsv \
  --in=src/strings/stringsFa.json \
  --out=src/strings/stringsFa.csv \
  --source=src/strings/stringsEn.json \
  --schema=src/strings/strings.schema.json
```

- `--in`: Strings JSON file to convert (used for the “Translation” column)
- `--out`: CSV file to write
- `--source`: Source (usually English) strings JSON file (used for the “Source” column)
- `--schema`: Strings JSON Schema generated by [ts-json-schema-generator](https://github.com/vega/ts-json-schema-generator) (used for the “Description” column). It must contain a `definitions.Strings` type whose top-level properties have types named `${Key}Strings` (e.g. `homePage` → `HomePageStrings`).

The CSV has the columns “Key”, “Source”, “Translation”, and “Description”, and is sorted by key (case-insensitive). Non-leaf keys and missing values have their “Source” and “Translation” set to `---`.

### convertStringsCsvToJson

```sh
npx convertStringsCsvToJson --in=src/strings/stringsFa.csv --out=src/strings/stringsFa.json
```

- `--in`: CSV file to convert. Only the “Key” and “Translation” columns are used; rows with a translation of `---` are skipped.
- `--out`: Strings JSON file to merge translations into (created if it doesn’t exist)

### syncAndSortStrings

```sh
npx syncAndSortStrings \
  --source=src/strings/stringsEn.json \
  --files=src/strings/stringsEn.json,src/strings/stringsFa.json
```

- `--source`: Source (usually English) strings JSON file to sync missing strings from
- `--files`: Comma-separated list of strings JSON files to sync and sort. Include the source file to sort and format it too.

### Using with npm scripts

```json
{
  "scripts": {
    "convert-strings-csv-to-json": "convertStringsCsvToJson",
    "convert-strings-json-to-csv": "convertStringsJsonToCsv --source=src/strings/stringsEn.json --schema=src/strings/strings.schema.json",
    "sync-and-sort-strings": "syncAndSortStrings --source=src/strings/stringsEn.json --files=src/strings/stringsEn.json,src/strings/stringsFa.json"
  }
}
```

Arguments passed to `npm run` must be preceded by `--`:

```sh
npm run convert-strings-json-to-csv -- --in=src/strings/stringsFa.json --out=src/strings/stringsFa.csv
npm run convert-strings-csv-to-json -- --in=src/strings/stringsFa.csv --out=src/strings/stringsFa.json
npm run sync-and-sort-strings
```

### Using the functions directly

The function behind each CLI tool is also exported: `stringsJsonToCsv`, `mergeStringsCsvIntoStrings`, and `syncAndSortLocaleStrings`. They operate on parsed objects and strings (no file I/O). See [`src/index.ts`](./src/index.ts).

## Development

This package is developed with Node.js 22+ (see `engines` field in `package.json`).

```sh
# Watch src and build into dist/ on change
npm run dev

# Build
npm run build

# Run ESLint, Prettier, TypeScript, and Vitest checks
npm run lint-test

# Run Vitest in watch mode
npm run vitest-watch
```

To try the CLI tools during development, build and run them with Node:

```sh
npm run build
node dist/bin/convertStringsJsonToCsv.js --help
```

### Testing in another project

```sh
# In this folder
npm run build
npx yalc publish

# In the other project
npx yalc add --dev @asl-19/string-scripts
npm install
```

### Publishing

```sh
npm publish
```

`prepublishOnly` builds and runs all checks first.
